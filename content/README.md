# Данные сайта

Все, что показывает сайт, лежит здесь в JSON. Сборка (`tools/build.py`) складывает эти файлы
в `assets/js` собранного сайта: `data.js`, `abstracts.js`, `citations.js`, `en-content.js`.
Скрипты из `tools/` читают и пишут эти файлы через общий модуль `tools/lib/store.py`,
поэтому формат у всех один: UTF-8, отступ в один пробел, перевод строки LF.

## Файлы данных

| Файл | Что внутри | Откуда берется |
|---|---|---|
| `site.json` | адрес сайта, почта, телефон, внешние ссылки | руками; `url` это адрес для сборки |
| `people.json` | сотрудники: имя, степень или ступень, должность | `tools/people/book.py` из книги |
| `directions.json` | научные направления | `tools/texts/directions.py` из `edit/DIRECTIONS_TEXT.md`, `heroTitle` и картинки руками |
| `publications.json` | публикации | `tools/publications/*.py` |
| `news.json` | новости со служебными полями (номер таблицы в анкете, заголовок из анкеты) | `tools/news/form.py` из анкеты |
| `abstracts.json` | авторские абстракты по DOI, на языке статьи | `tools/publications/abstracts.py` |
| `citations.json` | библиографические данные Crossref по DOI | `tools/publications/citations.py` |
| `english.json` | переводы направлений, людей и новостей | `tools/texts/english.py` из `edit/EN_*.md` |

Двое сотрудников в `people.json` в книге не значатся (Александра-Мария Иванова и Алексий
Валентюк): их данные взяты из анкет направлений, перенос из книги их не трогает.

Документы в `site.json` (политика обработки данных, сведения об организации) ведут на страницы
ИТМО: сайт будет жить на домене itmo.ru (решение владельца 24.09.2026), английских версий
у этих страниц нет.

## Папки

- `manual/` правки владельца, которые важнее всего, что отдают сервисы, и переживают любую
  пересборку: абстракты, даты, теги, ссылки на работы без DOI, заголовки новостей.
- `collected/` собранное из внешних сервисов: база статей сотрудников (OpenAlex, ORCID, Crossref)
  и карта квартилей журналов из выгрузок SJR. Собирать заново долго, поэтому лежит в git.
- `edit/` рабочие листы в markdown для правки руками. Скрипт выгружает лист, владелец правит,
  скрипт забирает правки ключом `--import` или `--import-md`.
