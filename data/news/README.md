# Анкета новостей

Здесь лежит `011_Новости.docx`, анкета, которой владелец ведет новости сайта.
Одна таблица это одна новость: дата, тег, заголовок, анонс и текст. Новую новость
удобно делать копией последней таблицы, номером новости считается номер таблицы,
а не число в метке.

Читает ее `python tools/news_from_form.py`: он переносит анкету в `docs/news.json`
и в `window.NEWS` в `assets/js/data.js`. Тексты владельца не переписываются,
чинятся только явные склейки слов (словарь `TYPOS` в скрипте).

Сам файл в git не уходит (правило в `.gitignore`). До 22.09.2026 анкета лежала
на рабочем столе рядом с папкой репозитория.
