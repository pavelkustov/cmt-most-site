# Оригиналы выгрузок SJR (Scimago)

Сюда кладутся файлы вида `scimagojr 2025.csv` — годовые выгрузки рейтинга журналов
со scimagojr.com (кнопка выгрузки на странице Journal Rankings). Из них
`python tools/enrich_publications.py` берет квартиль журнала: лучший квартиль
за самый свежий год, где журнал есть в рейтинге.

Сами файлы в git не уходят, они весят по 11 МБ (правило в `.gitignore`). Лежат только
на машине владельца. Если их нет, скрипт работает на разобранной карте
`docs/journal_quartiles.json`, которая в репозитории есть.

Сайт scimagojr.com закрыт Cloudflare и роботом не скачивается, файлы сохраняет владелец
руками. Поддерживаются и сжатые копии `scimagojr 2025.csv.gz`.

Сейчас лежат годы: 2013, 2016, 2018, 2020, 2021, 2022, 2023, 2024, 2025.
