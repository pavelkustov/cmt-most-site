# Оригиналы фотографий новостей

Сюда владелец складывает снимки к новостям. Имя файла это номер новости
в анкете `data/news/011_Новости.docx`.

Переносит их `python tools/news_photos.py`. Из каждого снимка он делает два кадра
в `assets/img`: `news-<имя>.webp` 3:2 для карточки и `news-<имя>-popup.webp`
почти квадратный для окна новости. Кадр выбирается по лицам, а где автоматика
промахнулась, точка кадра вбивается в словарь `FRAMES` внутри скрипта.
Один снимок переносится ключами `--file ПУТЬ --for ИД-НОВОСТИ`.

Оригиналы в git не уходят (правило в `.gitignore`), они весят под 60 МБ,
но удалять их нельзя: без них не перекадрировать снимок и не пересобрать
фотографии после правки анкеты. До 22.09.2026 они лежали в папке «Фото»
на рабочем столе.

Сейчас лежат 42 снимка.
