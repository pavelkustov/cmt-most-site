# Сайт ЦМТ «Мост»

Сайт Центра междисциплинарных технологий «Мост» физического факультета Университета ИТМО.
Сверстан по макету в Figma. Статический сайт на HTML, CSS и JS без сборки, публикуется через GitHub Pages.

## Страницы

| Файл | Что это |
|---|---|
| `index.html` | Главная: о центре, наука, индустрия, образование, новости |
| `direction.html?id=puf` | Страница научного направления (id из `assets/js/data.js`) |
| `publications.html` | Все публикации с поиском, фильтрами и видом «карточки / список» |
| `news.html` | Новости, новость месяца и попап (`news.html?open=<id>` открывает новость сразу) |

## Как посмотреть локально

```powershell
cd "$HOME\OneDrive\Рабочий стол\cmt-most-site"
python -m http.server 8000
```

Затем открыть http://localhost:8000. Сайт нужно открывать через сервер, а не двойным кликом по файлу.

## Как менять контент

Весь контент лежит в `assets/js/data.js`:

- `DIRECTIONS` содержит научные направления (карточки на главной и страницы направлений).
  Фон страницы направления берется из `hero`, а если его нет, из `image` карточки.
  `heroTitle` задает заголовок первого экрана: курсивная часть в `<em>`, перенос через `<br>`,
  строка, которая не должна переноситься даже шире границы, оборачивается в `<span class="line">`;
- `PUBLICATIONS` содержит публикации, новая добавляется копированием любого объекта.
  После добавления запустите `python tools/fetch_citations.py`: он скачает из Crossref по DOI данные для окна
  «Цитировать» (ГОСТ, MLA, APA, BibTeX, EndNote, RefMan, RefWorks) в `assets/js/citations.js`.
  Без этого цитата соберется из полей `data.js`, но без тома, номера и страниц;
- `NEWS` содержит новости, у новости месяца стоит `featured: true`.

Картинки кладутся в `assets/img/` (лучше в WebP, до 300 КБ), в данных указывается только имя файла.

## Проверка перед публикацией

```powershell
python tools/bump_assets.py    # метки версий ?v= у CSS/JS, чтобы браузеры не показывали старый кэш
python tools/smoke.py          # ошибки JS, битые картинки, горизонтальный скролл, фильтры, попап
python tools/smoke.py --shots  # то же и скриншоты в tools/shots/
```

Нужен Python с `playwright` (`pip install playwright` и `playwright install chromium`).

## Публикация на GitHub Pages

1. Создать репозиторий на GitHub и запушить ветку `main`.
2. Settings → Pages → Source: *Deploy from a branch*, ветка `main`, папка `/ (root)`.
3. Через 1–2 минуты сайт будет доступен по адресу `https://<аккаунт>.github.io/<репозиторий>/`.

Все пути в сайте относительные, поэтому он работает и в подпапке репозитория, и на своем домене.

## Структура

```
index.html, direction.html, publications.html, news.html
assets/css/style.css     стили (1rem = 10px на ширине 1920, дальше масштабируется)
assets/js/data.js        контент
assets/js/layout.js      шапка, подвал, иконки, типографика (предлоги не висят в конце строки)
assets/og                картинки превью ссылок 1200x630 (tools/make_share_images.py рисует их и PNG-иконки)
assets/icons/favicon.svg иконка сайта: мост из логотипа, перерисован в вектор
assets/js/main.js        логика страниц
assets/img, assets/icons картинки и иконки из Figma
design/                  скрипты выгрузки картинок из Figma (рендеры макета и исходники только локально)
docs/PROJECT.md          информация по проекту и список открытых вопросов
tools/                   смоук-тест и вспомогательные скрипты
```

Проверка опубликованного сайта: `python tools/smoke.py --base https://pavelkustov.github.io/cmt-most-site/`
