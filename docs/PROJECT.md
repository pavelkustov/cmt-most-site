# ЦМТ «Мост» — информация по проекту

## Источник

- Макет: https://www.figma.com/design/cTykc0aa3pAAjbvKz7ngiY/Untitled
- Секции макета: Компоненты, Главная, Направление (пустое и два заполненных, со списком и с карточками),
  Публикации, Новости, наведение на «Наука», попап новости.
- Рендеры всех страниц лежат в `design/render-*.png`, исходные PNG из Figma в `design/source-img/` (в git не идут).
- Ссылки на ассеты Figma в `design/assets_manifest.txt` живут около 7 дней (с 16.09.2026).
  Файл только локальный, в git не идет (временные ссылки Figma просит не публиковать).
  Повторная выгрузка: `python design/download_assets.py`, затем `python design/optimize_images.py`.
- 16.09.2026 оставшиеся картинки выгружены через Figma REST API (лимит MCP на Starter исчерпан):
  оригиналы лежат в `design/source-img/*-orig.*`, в WebP их переводит `python design/import_originals.py`.
  Для REST API нужен личный токен Figma (Settings → Security → Personal access tokens, scope File content: read),
  его не хранить в репозитории.

## Открытые вопросы по контенту

1. **Цифры направления «Неклонируемые метки» расходятся.** На главной в макете 19 человек и 10 публикаций,
   на странице направления 5 человек и 12 публикаций. На сайте сейчас везде 5 и 12 (публикаций в данных ровно 12).
2. **Карточки направлений кроме первых двух** в макете с одинаковыми цифрами «18 / 10» (заглушка).
   Описаний, команд и публикаций для них нет, страница показывает «Описание направления готовится».
   «Экологически чистая нано- и микротехнология»: в шаблоне 4 карточки команды подписаны одним именем
   «Yali Sun», у двух фото (девушка в очках, парень в очках) реальных имен нет, на сайт они не вынесены.
   Публикации этого направления в шаблоне повторяют чужую статью (про поляризацию), поэтому блок публикаций скрыт,
   хотя на карточке указано 7 публикаций.
3. **В макете «Публикации» и «Новости» счетчики-заглушки** («Найдено 14 работ», «Показано 6 из 219», «Всего 29 новостей»),
   на сайте они считаются по реальным данным.
4. **Новости-заглушки.** В макете все карточки одинаковые («Сотрудники центра выступили на ICLO-2026»).
   Нужны реальные новости.
5. **Ссылки без адреса:** «Политика по обработке персональных данных», «Информация об организации»,
   «Сайт нового физтеха» (сейчас physics.itmo.ru),
   «Оборудование → подробнее» (сейчас письмо на почту).
6. **Английская версия.** Переключатель EN есть, но перевода нет, кнопка неактивна с подсказкой.
7. Опечатка в макете «нанострукутры» на сайте исправлена на «наноструктуры». Буква «ё» в текстах заменена на «е».

## Решения

- Без фреймворков и сборки: GitHub Pages отдает файлы как есть, контент правится в одном `data.js`.
- Шрифты Inter и Roboto из макета, подключены с Google Fonts.
- Картинки публикаций размыты с зеленой подложкой, как в макете, при наведении становятся четкими.
